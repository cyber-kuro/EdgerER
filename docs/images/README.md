# Images

This directory contains public validation plots generated from the supporting evidence package.

Recommended final repository screenshots, captured after the current branding and device-lifecycle fixes, may be added with names such as:

- `dashboard_overview.png`
- `registration_device_dropdown.png`
- `live_physical_node.png`
- `priority_patient.png`
- `device_registry.png`
- `offline_reconnect.png`
- `handoff_summary.png`

Avoid publishing screenshots containing private names, personal paths, local credentials, or obsolete UI branding.
