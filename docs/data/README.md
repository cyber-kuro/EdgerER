# Supporting Data

- `pulse_oximeter_paired_observations.csv` - paired EdgeER and consumer-reference HR/SpO2 observations
- `rr_validation_summary.csv` - exploratory RR candidate, confidence, and usability summary
- `power_observation_summary.csv` - logged idle and active voltage/current/power ranges
- `pulse_oximeter_raw_data.csv` - preserved raw PPG recording included in the bench package
- `EdgeER_Bench_Evaluation_Data.zip` - compact original supporting data bundle

These files support engineering interpretation and exploratory bench comparison. They are not clinical-validation datasets.
