# Safety and Intended Use

EdgeER is an investigational engineering prototype developed for education, portfolio demonstration, software engineering, embedded-systems experimentation, and research preparation.

It is not:

- a certified medical device,
- a diagnostic system,
- a replacement for professional clinical assessment,
- intended for use in patient-care decisions,
- validated for emergency-department deployment,
- approved for monitoring actual patients.

Low-cost sensor measurements may be inaccurate, delayed, unavailable, or affected by motion, contact quality, placement, lighting, perfusion, network failure, or software error.

PPG-derived respiratory rate is experimental. Candidate RR values are transmitted numerically only when the estimator's quality and confidence rules permit; otherwise the value is withheld.

The current evidence demonstrates software behavior, engineering reliability, and exploratory bench agreement only. It does not establish clinical accuracy, clinical safety, or regulatory compliance.
