# EdgeER v1.0 Scope

## Included in v1.0

- One stable Raspberry Pi physical node
- One continuous MAX30102 hardware reader
- Shared timestamped PPG buffer
- Buffered HR, SpO2, PPG-quality, and experimental RR processing
- Confidence-aware withholding of unreliable RR values
- Validated packet construction and server-side authority
- Patient, encounter, device, priority, timer, dismissal, readmission, and handoff workflows
- Multi-device simulator with fault scenarios
- Reproducible software validation
- Public technical documentation and demonstration materials

## Explicitly outside v1.0

- Clinical validation or medical-device claims
- Hospital deployment
- ESP32 integration
- Multiple physical-node fleet
- Blood-pressure hardware
- Complete NEWS2 scoring
- Diagnostic or treatment recommendations
- LLM-generated clinical content
- Custom PCB or commercial enclosure
- Production authentication or regulatory certification

The excluded capabilities are tracked as future work and do not delay the portfolio release.
