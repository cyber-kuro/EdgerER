# License Selection

No software license has been selected in this documentation package. Before making the repository public, choose a license that matches the intended reuse policy.

Common options include:

- **MIT License:** permissive reuse with attribution
- **Apache License 2.0:** permissive reuse with an explicit patent grant
- **No license:** others may view the repository but do not receive broad reuse rights

The safety disclaimer and intended-use limitations should remain visible regardless of the software license selected.
